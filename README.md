# 郵箱管理

Python + pywebview（桌面窗口）+ Vue 3（界面），數據存在本地 SQLite。

## 使用

直接運行 `dist\MailManager.exe`。數據文件 `mail_data.db` 會自動創建在 exe 同目錄（便攜，複製整個文件夾即可遷移/備份）。

## 主密碼加密

- 首次啟動要設置主密碼，之後每次啟動輸入主密碼解鎖。
- 密碼、2FA 密鑰、輔助郵箱密碼用 AES-256-GCM 加密存儲，密鑰由主密碼經 scrypt 派生（`vault.py`）；郵箱、輔助郵箱、備註、分組不加密，方便搜索。
- 側邊欄「🔒 鎖定」立即鎖定；「⚙ 安全設置」可修改主密碼（所有數據會用新密碼重新加密）和設置閒置自動鎖定（默認 15 分鐘）。
- 舊版本留下的明文數據，在設置主密碼時會自動加密。
- **忘記主密碼無法恢復數據**。導出的 CSV / TXT 是明文，請妥善保管。

## 功能

- 多列表：左側「列表」可新增 / 重命名 / 刪除
- 自定義列（列設置）：文本、顏色標記、國家/地區（國旗 + 代碼）、Emoji、縮略圖；表格裡點單元格直接編輯，也可批量設置
- 翻頁：每頁 20 / 50 / 100 / 200 條，可跳頁
- 主題：明亮 / 暗黑 / 跟隨系統；語言：繁體中文 / 简体中文 / English / 日本語
- 記憶：列表、分組、篩選、排序、頁碼、滾動位置、列顯示等存在數據庫裡，重開軟件自動恢復
- 分組：顏色分組，側邊欄點擊即篩選；批量設置分組
- 字段：郵箱、密碼、2FA 密鑰、輔助郵箱、輔助郵箱密碼、手機號、狀態、備註
- 2FA：自動生成實時驗證碼，點擊即複製；支持 Base32 密鑰或 `otpauth://` 鏈接
- 搜索：郵箱 / 輔助郵箱 / 備註 / 手機 / 自定義列；忽略 `. _ -` 等符號（`johndoe` 能搜到 `john.doe@…`）；多個郵箱用空格分隔可批量查找
- 篩選：狀態、郵箱類型（按域名，自動識別 gmail / outlook / …）、有無 2FA、有無輔助郵箱
- 序號列：按當前排序/篩選顯示行號（可在列設置裡隱藏或調整位置）
- 列：可勾選顯示、自由調整順序（拖動表頭或在「列設置」裡 ↑↓），拖動表頭右邊緣調整列寬（雙擊恢復默認），順序和列寬自動記憶；表格超寬時出現橫向滾動條，操作列固定在右側
- 批量導入：
  - **智能識別**（默認）：不管順序，自動判斷每一段是郵箱、密碼、輔助郵箱、輔助郵箱密碼、2FA、地區、手機、ClientID、令牌，例如 `abc@gmail.com/Passw0rd/backup@outlook.com/JBSWY3DPEHPK3PXP/us`
  - **按順序指定**：手動選每一列的字段（含「國家/地區」），有快速格式按鈕
  - 分隔符自動識別 `----` Tab `|` `/` `,` `;` 空格 `:`；自動去重；可同時給導入的郵箱打顏色標記、設置國家
  - 地區（us / USA / uk / 日本 …）寫入「國家/地區」列，列表沒有該列時自動新增
  - 無法識別的行會單獨列出；配置了 AI 時**自動**交給 AI 糾錯（粘貼停下約 1 秒後開始，新增的行增量糾錯），也可「原樣導入」
- AI 糾錯（⚙ 設置 → AI 糾錯）：OpenAI 兼容協議（DeepSeek / OpenAI / 通義千問 / 硅基流動 / OpenRouter / Ollama 一鍵預設），填 API 地址、模型、Key（Key 用主密碼加密保存），提示詞可修改。結果流式顯示，逐行核對、可直接修改，勾選的行點「導入」一起導入。**注意：會把這些行（含密碼）發送給所配置的 AI 服務。**
- 🤖 AI 助手（工具欄右側）：像跟人說話一樣讓 AI 直接操作軟件，幾乎所有功能都能做：
  - 查詢、統計、查重、跨列表查找；篩選、搜索、排序、翻頁、勾選
  - 新增郵箱（直接把賬號文本發給它，任意格式，可同時指定分組、狀態、國家、自定義列如「編號」）、修改任意字段/狀態/分組/備註/自定義列、刪除、移動列表
  - 管理列（新增/改名/改類型/刪除/顯示隱藏/調整順序和寬度）、分組、列表
  - 查看 2FA 驗證碼、收取郵件和驗證碼、複製/導出、批量創建自建輔助郵箱、改主題/語言/自動鎖定
  - 模板 `{email}` `{user}` `{domain}` `{index}` `{random}`（隨機密碼）
  - 修改類操作默認在對話裡確認（可勾「自動執行」）；刪除類總是確認；AI 做的修改可以點「↶ 撤銷」或直接說「撤銷」
  - 默認不把密碼、2FA 密鑰、令牌發給 AI（勾選「允許讀取密碼」後才可以）；複製/導出在本地完成。鎖定時清空對話。
- 自建輔助郵箱（需要 BillionMail 管理員模式）：編輯郵箱時，輔助郵箱左側選「自建 @域名」，自動以主郵箱用戶名創建郵箱（`123@gmail.com` → `123@demo.com`，`.` `+後綴` 等去掉，重名自動加數字），隨機密碼，自動填入並保存；也可在批量操作欄「創建自建輔助郵箱…」批量創建（已有輔助郵箱的跳過）。域名來自 BillionMail 後台 + 設置裡的自建域名。
- 國家篩選：篩選欄可輸入多個國家（`usd/jpr/sgd 韓國`），支持二位/三位代碼、貨幣、電話區號、四種語言的國家名稱，打錯一兩個字母也能匹配；國家選擇框同樣支持，↑↓ + Enter 快速選擇
- 導出：CSV（Excel 可直接打開）或 TXT，導出選中或當前篩選結果
- 點擊任意單元格複製；雙擊行編輯；快捷鍵 Ctrl+F 搜索、Ctrl+N 新增、Ctrl+S 保存、Esc 關閉

## 自建郵箱收信（BillionMail）

在「⚙ 設置 → 自建郵箱收信」裡填：

- 服務器地址：BillionMail 的郵件域名或 IP；端口 `993`，勾選 SSL/TLS
- 校驗證書：BillionMail 默認自簽證書時不要勾；已簽發正式證書可以勾上
- 自建域名：例如 `mydomain.com`，只有這些域名的郵箱會顯示 📥；留空則所有輔助郵箱都顯示
- 先點「測試連接」確認能連通

之後鼠標移到表格的輔助郵箱（或主郵箱）上會出現 📥，點開即收信：同時讀取 INBOX 和 Junk，
自動提取驗證碼，頂部大字顯示最新驗證碼，每 5 秒自動刷新，可勾選「新驗證碼自動複製」。
登錄用 **完整郵箱地址 + 輔助郵箱密碼**（主郵箱用密碼字段）。登錄失敗會自動停止刷新，避免觸發 BillionMail 默認開啟的 fail2ban。

郵件 HTML 在無腳本的沙箱裡顯示，並禁止加載任何外部圖片/資源。

## 微軟郵箱（Outlook / Hotmail / Live）

輔助郵箱或主郵箱是微軟郵箱時，自動走 `outlook.office365.com`，無需填「自建郵箱服務器」。兩種方式：

- **僅郵箱+密碼**：`郵箱----密碼`。注意微軟已對多數賬號關閉密碼直連 IMAP，這種多半收不到，僅作兜底。
- **帶令牌（OAuth2，推薦）**：`郵箱----密碼----ClientID----令牌`。ClientID 填應用的 client id，令牌填 refresh token。程序用它們換取 access token 再登錄，穩定可用。

**導入**：批量導入窗口頂部有「快速格式」按鈕，點「微軟帶令牌」會自動把字段順序設成 `郵箱 / 密碼 / ClientID / 令牌`。
**單條編輯**：編輯郵箱時填「ClientID」和「令牌」兩欄即可。令牌用主密碼加密存儲。

### 推薦：BillionMail 管理員模式（只填一次後台，不用逐個填郵箱密碼）

「⚙ 設置 → BillionMail 後台管理員模式」勾選啟用，填：

- 後台地址：例如 `https://mail.example.com`
- 安全入口路徑：BillionMail 後台的隨機入口，例如 `/xxxxxxxx`
- 管理員賬號 / 密碼：登錄後台用的那組（管理員密碼用主密碼加密保存）
- 點「測試後台登錄」確認，再保存

啟用後，自建域名的郵箱記錄**不用再填密碼**：收信時程序以管理員身份登錄後台，自動取回該郵箱的登錄密碼再收信（取到的密碼只緩存在內存，鎖定即清）。原理是 BillionMail 後台的「複製登錄信息」本來就能拿到郵箱密碼，這裡把它自動化了。

> 不想用管理員模式時，也可以給每條記錄單獨填「輔助郵箱密碼」，程序就用該密碼直接登錄 IMAP 收信。

## 開發

```bash
.venv\Scripts\python.exe main.py
```

瀏覽器調試界面：`.venv\Scripts\python.exe devserver.py`，然後打開 http://127.0.0.1:8765/?dev（使用獨立的 `dev_data.db`）。

重新打包：運行 `build.bat`，輸出 `dist\MailManager.exe`。

## 文件

- `backend.py` — 數據庫與所有 API（後續的自建郵箱收信 / 解碼可在這裡加新方法）
- `vault.py` — 主密碼派生密鑰與字段加解密
- `mailfetch.py` — IMAP 收信（自建 / 微軟 OAuth2）、郵件解析、驗證碼提取
- `billionmail.py` — BillionMail 後台管理員客戶端（取郵箱登錄密碼）
- `aifix.py` — AI 糾錯（OpenAI 兼容 /chat/completions 流式請求、默認提示詞）
- `web/importer.js` — 批量導入的分行、字段識別（智能 / 按順序）
- `web/agent.js` — AI 助手（工具定義、對話循環、工具執行）
- `assets/icon.ico` — 程序圖標，由 `tools/make_icon.py` 生成（需要 Pillow）
- `main.py` — 桌面窗口入口
- `web/` — 界面（index.html / app.js / style.css / Vue）
