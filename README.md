# 郵箱管理 · MailManager

一個本地運行的 Windows 桌面工具，用來管理大量郵箱賬號：密碼、2FA、備用碼加密保存，批量導入、分組篩選、收信取驗證碼，還有能直接操作軟件的 AI 助手，以及給腳本和 AI 工具用的只讀 API / MCP 接口。

所有數據都存在本地 SQLite 文件裡，不經過任何雲端服務（只有你主動配置的 AI 服務和郵件服務器例外）。

**技術棧**：Python + [pywebview](https://pywebview.flowrl.com/)（桌面窗口）+ Vue 3（界面）+ SQLite

## 主要功能

- 🔐 **主密碼加密**：密碼、2FA 密鑰、令牌等敏感字段用 AES-256-GCM 加密，密鑰由主密碼經 scrypt 派生
- 📋 **表格管理**：多列表、自定義列（文本 / 顏色 / 國家 / Emoji / 縮略圖）、分組（一個郵箱可在多個分組）、家庭組、篩選、排序、搜索
- 🔢 **2FA 與備用碼**：實時生成驗證碼，點擊複製；Google 備用碼自動識別、逐個標記已用
- 📥 **批量導入**：不管字段順序自動識別郵箱、密碼、輔助郵箱、2FA、地區、手機號、令牌等；識別不了的行可交給 AI 糾錯
- 📨 **收信取驗證碼**：支持自建 BillionMail 郵箱和微軟郵箱（OAuth2），自動提取驗證碼
- 🤖 **AI 助手**：用自然語言查詢、新增、修改、統計、導出，支持技能和經驗記憶（OpenAI 兼容接口，DeepSeek / OpenAI / 通義千問 / Ollama 等）
- 🔌 **本地 API + MCP**：只讀 HTTP 接口，Claude Code、Cursor 等 AI 工具可直接接入查詢
- 🕘 **操作記錄**：密碼、2FA、備用碼、輔助郵箱、備註、狀態等敏感字段的變更前 → 變更後，刪除的郵箱（可找回刪除前的內容），主密碼 / API 密鑰的改動；標明操作人（自己 / AI 助手 / 同步），加密保存，最多 9999 條，可按操作人、項目、日期篩選和搜索
- 🌐 繁體中文 / 简体中文 / English / 日本語，明亮 / 暗黑主題

## 快速開始

### 直接下載

到 [Releases](https://github.com/qianyexiaoqian/mail-qianye/releases/latest) 下載最新的 `MailManager.exe`，放進一個單獨的文件夾裡雙擊運行，首次啟動會要求設置主密碼。數據文件 `mail_data.db` 會自動創建在 exe 同目錄。

exe 沒有數字簽名，首次運行時 Windows SmartScreen 可能提示「已保護你的電腦」，點「更多信息 → 仍要運行」即可。

### 環境要求

- Windows 10 / 11（需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，Windows 11 已自帶）
- Python 3.12（從源碼運行或打包時需要）

### 從源碼運行

```bash
git clone https://github.com/qianyexiaoqian/mail-qianye.git
cd mail-qianye
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

首次啟動會要求設置主密碼。

### 打包成 exe

```bash
.venv\Scripts\pip install pyinstaller
build.bat
```

輸出單文件 `dist\MailManager.exe`。數據文件 `mail_data.db` 會自動創建在 exe 同目錄，便攜使用：複製整個文件夾即可遷移或備份。

### 瀏覽器調試

```bash
.venv\Scripts\python.exe devserver.py
```

然後打開 http://127.0.0.1:8765/?dev 。調試模式使用獨立的 `dev_data.db`，不影響正式數據。

## 安全說明

- 首次啟動設置主密碼，之後每次啟動輸入主密碼解鎖。
- 密碼、2FA 密鑰、輔助郵箱密碼、OAuth 令牌、AI Key、AI 對話記錄等用 **AES-256-GCM** 加密存儲，密鑰由主密碼經 **scrypt** 派生（見 `vault.py`）。郵箱地址、輔助郵箱、備註、分組不加密，方便搜索。
- 側邊欄「🔒 鎖定」立即鎖定；「⚙ 安全設置」可修改主密碼（全部數據會用新密碼重新加密）和設置閒置自動鎖定（默認 15 分鐘）。
- 舊版本留下的明文數據，在設置主密碼時會自動加密。
- **忘記主密碼無法恢復數據。** 導出的 CSV / TXT 是明文，請妥善保管。
- AI 糾錯會把待糾錯的行（含密碼）發給你配置的 AI 服務；AI 助手默認不把密碼、2FA 密鑰、令牌發給 AI，需要手動勾選「允許讀取密碼」。
- 本地 API 默認關閉，開啟後默認只監聽 `127.0.0.1`。

- 打開時自動從後台同步，也可以點「⟳ 同步」：後台新增的加進來、刪掉的移除，密碼、停用狀態、轉發更新
- 「＋ 新建郵箱」：選域名，按名稱或隨機生成批量創建，密碼每個隨機或統一設置；建好後可一鍵複製全部
- 刪除郵箱會同時在後台刪除（郵件和它的轉發也會刪除，不可恢復）；修改密碼、停用狀態會同步到後台
- 郵件轉發：編輯郵箱時在「轉發到」填郵箱（一行一個，可以填多個），或者勾選多個郵箱後用「轉發」批量設置 / 取消。郵件會同時發到郵箱自己和轉發的郵箱；郵箱停用後轉發照常生效（只轉發，表格裡顯示「僅轉發」）。需要 2025 年 9 月以後的 BillionMail（後台「設置」裡有「轉發」）

> 「測試後台登錄」提示「後台沒有響應（連接超時）」：程序 10 秒內連不上後台就會報這個錯。通常是服務器宕機、BillionMail 容器沒在運行（`docker ps` 檢查），或本機 IP 被 fail2ban / 防火牆封禁。先用瀏覽器打開後台地址確認。

<details>
<summary><b>微軟郵箱（Outlook / Hotmail / Live）</b></summary>

輔助郵箱或主郵箱是微軟郵箱時，自動走 `outlook.office365.com`，不需要 BillionMail：

- **僅郵箱 + 密碼**：`郵箱----密碼`。微軟已對多數賬號關閉密碼直連 IMAP，這種多半收不到，僅作兜底。
- **帶令牌（OAuth2，推薦）**：`郵箱----密碼----ClientID----令牌`。ClientID 填應用的 client id，令牌填 refresh token，程序用它們換取 access token 再登錄。

批量導入窗口頂部的「快速格式 → 微軟帶令牌」會自動把字段順序設好；單條編輯時填「ClientID」和「令牌」兩欄即可。令牌用主密碼加密存儲。

</details>

## 本地 API 與 MCP（只讀）

默認關閉。點側邊欄的「🔌 API 接口」，打開右上角的開關即可。API 密鑰自動隨機生成（不能手動填寫，可以重新生成，舊的立即失效）。頁面裡有完整的接口文檔、請求 / 返回示例和在線調試。

- 默認只監聽 `127.0.0.1`；勾選「允許局域網其他設備訪問」才會監聽 `0.0.0.0`
- 每個請求都要帶密鑰：`Authorization: Bearer <密鑰>`（推薦），或 `X-API-Token` 頭，或 URL 參數 `token=`
- 「軟件鎖定時也能讀取」默認打開：數據密鑰用 API 密鑰另外加密一份，帶正確密鑰的請求在軟件鎖定時也能讀到數據；關掉後鎖定時返回 `423`
- 數據庫裡只保存密鑰的哈希和用主密碼加密的密鑰，沒有明文；請求記錄裡也不記錄密鑰

| 接口 | 說明 |
| --- | --- |
| `GET /api/accounts` | 郵箱列表。篩選：`sheet`、`group`（`none` = 未分組）、`family`、`role`、`status`、`email`（逗號分隔）、`search`、`has_2fa`；`fields`、`limit`、`offset`；`format=txt` + `sep` 輸出純文本 |
| `GET /api/account?email=` | 單個郵箱的全部信息（也可以 `id=`） |
| `GET /api/2fa?email=` | 當前 2FA 驗證碼和剩餘秒數（多個郵箱用逗號；或 `secret=` 直接算） |
| `GET /api/groups` / `sheets` / `families` | 分組、列表、家庭組 |
| `GET /api/health` | 服務狀態、是否鎖定 |

```bash
curl -H "Authorization: Bearer <Token>" "http://127.0.0.1:8686/api/accounts?group=work"
curl "http://127.0.0.1:8686/api/accounts?format=txt&fields=email,password,totp_code&token=<Token>"
```

### MCP

同一個服務上的 `http://127.0.0.1:8686/mcp`，傳輸方式是 Streamable HTTP，用同一個 API 密鑰認證。接入後可以直接對 AI 說「把 work 分組的郵箱和 2FA 驗證碼列出來」。工具全部只讀：`list_accounts`、`get_account`、`get_2fa_code`、`export_accounts_text`、`list_groups`、`list_sheets`、`list_families`。

```bash
claude mcp add --transport http mail-manager http://127.0.0.1:8686/mcp --header "Authorization: Bearer <Token>"
```

API 接口頁面的「MCP」分類裡有 Cursor、Cherry Studio 等其他工具的配置示例。

## 項目結構

```
├── main.py            桌面窗口入口
├── backend.py         數據庫與全部後端 API
├── vault.py           主密碼派生密鑰、字段加解密
├── mailfetch.py       IMAP 收信（自建 / 微軟 OAuth2）、郵件解析、驗證碼提取
├── billionmail.py     BillionMail 後台管理員客戶端
├── aifix.py           AI 糾錯（OpenAI 兼容流式請求、默認提示詞）
├── fsagent.py         AI 助手操作電腦用的文件 / 命令工具
├── apiserver.py       本地只讀 HTTP API（Token 校驗、請求記錄）
├── mcpserver.py       MCP 接口（JSON-RPC、工具定義），掛在 API 服務的 /mcp
├── devserver.py       瀏覽器調試服務器
├── build.bat          PyInstaller 打包腳本
├── tools/make_icon.py 生成程序圖標（需要 Pillow）
└── web/               界面
    ├── index.html / app.js / style.css
    ├── agent.js       AI 助手（工具定義、對話循環、工具執行）
    ├── importer.js    批量導入的分行和字段識別
    ├── apidocs.js     API 接口頁面的文檔數據
    ├── i18n.js        四種語言的界面文字
    └── countries.js   國家 / 地區數據
```

## 注意

- 這是個人使用的工具，請只用來管理你自己有權使用的賬號，並遵守各郵件服務商的使用條款。
- 數據文件 `*.db` 已在 `.gitignore` 中排除，不要把它提交到倉庫。
